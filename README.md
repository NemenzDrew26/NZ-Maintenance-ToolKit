# NZ-Maintenance-ToolKit
A simple, lightweight Batch script to clean, repair, and manage Windows settings without bloatware.

Honestly made this out of pure frustration lol. I wasn't about to install another sketchy "PC Speedup 2026 Free" bloatware just to clear cache and repair corrupted files. Shoved all the native Windows commands I actually use into one file so we don't have to suffer anymore.
